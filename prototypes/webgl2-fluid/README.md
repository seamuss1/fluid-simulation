# Archived WebGL2 Prototype

This folder preserves the earlier browser-based GPU fluid study as an archived prototype.

- `index.html`, `app.js`, `styles.css`: archived WebGL2 pass-stack demo
- `smoke*.png`: captured smoke-test/reference images

This prototype remains runnable for comparison and visual reference, but it is not the forward path for the repository.
The FluidX3D benchmark script and vendored reference checkout now live under `benchmarks/research/fluidx3d/`.
