# FluidX3D Research Benchmark

This folder preserves the FluidX3D helper assets as research material.

- `run-fluidx3d-benchmark.ps1`: Windows benchmark helper for the vendored checkout
- `vsconfig-fluidx3d.vsconfig`: Visual Studio component profile used by the helper
- `FluidX3D/`: vendored reference checkout kept out of the main CMake build

Nothing in this folder is wired into the top-level native build.
